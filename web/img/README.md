# Pictures for the intro and the info drawer

All are screenshots of the viewer itself (save PNG, or P, in figure mode),
converted with `python scripts/web_images.py name=file.png ...`. Until all
four intro pictures exist the intro shows its four steps as text.

| file | what it shows | how to take it |
|---|---|---|
| intro-1.webp | one tile of real ground | story: capture, figure mode, save |
| intro-2.webp | tiles with their edge colours | story: tiles |
| intro-3.webp | the world, materials at random | story: world |
| intro-4.webp | the same world, placed by the rule | story: rule (same camera as 3) |
| info-tiles.webp | a few tiles, edge colours on | story: tiles, closer |
| info-rule.webp | rule off beside rule on | `scripts/figures.py` rule figure, or the two figure presets side by side |
| info-farfield.webp | far field and splats | research: debug views, colour by level, survey view |
| info-repetition.webp | the desert sets compared | the repetition figure from `scripts/figures.py` |

Wide 4:3 crops read best in the intro strip.
